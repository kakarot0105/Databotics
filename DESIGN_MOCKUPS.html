🎬 Key Pages & Layouts

1. Dashboard (Upload & Profile)

Left Sidebar: Sticky navigation with 7 main sections (Upload, Profile, Validate, Clean, Query, Anomaly, AI Assist)

Main Content: Large drag-and-drop zone for file uploads with glassmorphism styling

Animations: Progress bar with glow, smooth 300ms transitions

2. Data Profile Page

Stats Cards: 4 large cards showing Rows, Columns, Missing Values, Numeric Columns

Auto Insights: 4-6 AI-generated cards with emojis and key findings

Charts: 4 interactive visualizations (Bar, Pie, Line, Scatter)

Table: Detailed column statistics with min, max, mean, std, type

3. Data Cleaning Page

Assessment: Checkboxes for remove duplicates, drop nulls, drop columns

Strategy: Dropdown to select missing value imputation strategy

Preview: Real-time summary of changes before applying

Report: Cleaning report with operation log and statistics

4. Transformation Page

Transformations: Drag-and-drop cards for each applied transformation

Methods: Normalize (Min-Max/Z-Score/Robust), Scale, Log, One-Hot Encode

Undo/Redo: Full operation history with one-click undo

Download: Export transformed dataset in CSV format

5. AI Insights Page

Auto Insights: 3-5 detailed findings from Claude API

Color Coded: Green for positive, Yellow for warnings, Blue for info

NLP Query: Ask questions like "Top countries by sales" in natural language

Recommendations: Actionable next steps for each insight

✨ Glassmorphism Design

Backdrop Filter: blur(20px) for cards, blur(30px) for sticky elements

Transparency: rgba(255,255,255,0.15) dark mode, rgba(30,41,59,0.4) light mode

Border: 1px solid rgba(255,255,255,0.2) for subtle definition

Shadow: 0 8px 32px rgba(31,38,135,0.15) for depth

Radius: 16px for smooth, modern curves

🔄 User Workflows

Workflow 1: Quick Data Analysis

  1. 🔐 Login to Databotics
  2. 📤 Upload CSV file (drag-and-drop or browse)
  3. 📊 Auto Profile generated instantly
  4. 💡 View 3-5 auto-generated insights
  5. ⬇️ Export report

⏱️ Total Time: ~30 seconds

Workflow 2: Data Cleaning

  1. 📤 Upload raw data
  2. 🔍 Review missing values and quality issues
  3. 🤖 Get auto-generated cleaning suggestions
  4. ⚙️ Adjust cleaning plan (duplicates, nulls, columns)
  5. 👁️ Preview results before applying
  6. ✅ Apply and download cleaned data

⏱️ Total Time: ~2 minutes

Workflow 3: ML Data Preparation

  1. 📤 Upload raw dataset
  2. 📊 Analyze (profile, correlations, outliers)
  3. 🧹 Clean (duplicates, missing values, nulls)
  4. 🔄 Transform (normalize, scale, encode)
  5. ✔️ Validate (no missing, proper distributions)
  6. ⬇️ Export ML-ready dataset

⏱️ Total Time: ~5 minutes
